# 需求规格说明书

## 基于深度学习的工业产品表面缺陷智能检测系统

---

## 1. 引言

### 1.1 编写目的

本文档详细描述"基于深度学习的工业产品表面缺陷智能检测系统"的功能需求和非功能需求，作为系统设计、开发、测试和验收的依据。

### 1.2 项目背景

制造业产品质量检测是生产流程中的关键环节。传统人工目视检测存在效率低、一致性差、漏检率高等问题。本系统运用深度学习和计算机视觉技术，实现工业产品表面缺陷的自动化识别与定位，提升质量检测的效率和准确性。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| CNN | 卷积神经网络（Convolutional Neural Network） |
| YOLO | You Only Look Once，单阶段目标检测算法 |
| mAP | 平均精度均值（mean Average Precision） |
| B/S | 浏览器/服务器架构（Browser/Server） |
| API | 应用程序编程接口（Application Programming Interface） |
| NMS | 非极大值抑制（Non-Maximum Suppression） |

---

## 2. 总体描述

### 2.1 产品愿景

开发一个面向制造/工业场景的 B/S 架构智能检测系统，用户通过浏览器上传工业产品表面图片，系统自动调用深度学习模型进行缺陷识别与定位，替代传统人工目视检测。

### 2.2 用户角色

| 角色 | 描述 | 权限 |
|------|------|------|
| 普通用户 | 质量检测人员 | 上传检测、查看自己的历史记录、导出报告 |
| 管理员 | 系统管理员 | 普通用户权限 + 模型管理、阈值配置、查看全局统计 |

### 2.3 运行环境

- **服务端**：Python 3.10+，Flask，PyTorch，OpenCV，SQLite
- **客户端**：Chrome / Edge / Firefox 现代浏览器
- **操作系统**：Windows / Linux / macOS
- **硬件要求**：CPU 4核以上，内存 8GB 以上（有 GPU 更佳）

## 3. 功能需求

### 3.1 用户管理模块

#### FR-1.1 用户注册
- 输入：用户名（3-50字符）、密码（≥6位）、确认密码
- 处理：校验用户名唯一性，密码哈希存储
- 输出：注册成功/失败提示
- 异常：用户名已存在 → 409；参数不合法 → 400

#### FR-1.2 用户登录
- 输入：用户名、密码
- 处理：验证密码，创建 Session
- 输出：登录成功，返回用户信息
- 异常：用户名或密码错误 → 401

#### FR-1.3 用户登出
- 处理：清除 Session
- 输出：登出成功

#### FR-1.4 获取当前用户信息
- 前置条件：已登录
- 输出：用户 ID、用户名、角色、注册时间

### 3.2 图像上传与预处理模块

#### FR-2.1 单张图片上传
- 输入：图片文件（JPG/PNG/BMP，≤10MB）
- 处理：文件类型校验、大小校验、生成唯一文件名、保存到服务器
- 输出：文件保存路径

#### FR-2.2 批量图片上传
- 输入：最多 10 张图片
- 处理：逐张校验和保存
- 输出：每张图片的处理结果

#### FR-2.3 图像预处理
- 尺寸归一化：分类模型 224×224，检测模型 640×640（Letterbox）
- 像素归一化：[0,255] → [0,1]
- 颜色空间：BGR → RGB
- 张量转换：HWC → CHW → Batch

### 3.3 缺陷检测模块

#### FR-3.1 快速模式检测（仅分类）
- 输入：预处理后的图像张量
- 处理：ResNet50 分类模型前向推理，Softmax 输出概率
- 输出：预测类别、各类别概率、是否有缺陷
- 性能：单张推理 ≤ 1 秒（CPU）

#### FR-3.2 精确模式检测（分类+定位）
- 输入：预处理后的图像张量
- 处理：
  1. ResNet50 分类判断是否有缺陷
  2. 如有缺陷，YOLOv8 检测模型定位缺陷位置
  3. NMS 后处理过滤重叠框
  4. 坐标映射回原图尺寸
- 输出：缺陷列表（类别、置信度、边界框、面积）
- 性能：单张推理 ≤ 3 秒（CPU）

#### FR-3.3 检测阈值配置
- 置信度阈值：默认 0.25，范围 0.1-0.9（管理员可配置）
- IoU 阈值：默认 0.45，范围 0.1-0.9（管理员可配置）

### 3.4 结果展示与导出模块

#### FR-4.1 检测结果可视化
- 在原图上绘制缺陷边界框（不同类别不同颜色）
- 标注类别名称和置信度
- 显示分类概率分布条形图

#### FR-4.2 检测统计展示
- 缺陷数量、平均置信度、推理耗时
- 各类别概率分布

#### FR-4.3 单条记录导出
- 格式：CSV
- 内容：记录基本信息 + 缺陷详情

#### FR-4.4 全部记录导出
- 格式：CSV
- 内容：所有检测记录的摘要信息

### 3.5 历史记录管理模块

#### FR-5.1 记录列表查询
- 分页：每页 10 条，支持翻页
- 筛选：缺陷类型、是否有缺陷、日期范围
- 排序：按检测时间倒序

#### FR-5.2 记录详情查看
- 显示原始图片和检测结果图片
- 显示记录基本信息和缺陷详情列表

#### FR-5.3 记录删除
- 前置条件：记录属于当前用户
- 处理：删除数据库记录和关联的图片文件

### 3.6 统计仪表盘模块

#### FR-6.1 概览统计
- 总检测次数、缺陷样本数、缺陷率、平均置信度

#### FR-6.2 检测趋势
- 近 7 天每日检测量折线图

#### FR-6.3 缺陷类型分布
- 各类缺陷数量饼图

#### FR-6.4 模型性能统计
- 检测模式使用情况
- 各类别平均置信度

### 3.7 模型管理模块（管理员）

#### FR-7.1 模型列表查看
- 显示当前加载的分类模型和检测模型信息
- 显示模型状态（已加载/模拟模式）、版本、输入尺寸

#### FR-7.2 检测阈值更新
- 更新置信度阈值和 IoU 阈值
- 实时生效

## 4. 非功能需求

### 4.1 性能需求

| 指标 | 要求 |
|------|------|
| 单张图片检测响应时间 | ≤ 3 秒（CPU 环境） |
| 分类模型准确率 | ≥ 90%（NEU-DET 测试集） |
| 检测模型 mAP@0.5 | ≥ 0.80（NEU-DET 测试集） |
| 并发用户数 | ≥ 5 |
| 页面加载时间 | ≤ 2 秒 |

### 4.2 可用性需求
- 界面简洁友好，操作流程 ≤ 3 步完成检测
- 提供操作提示和错误提示
- 支持响应式布局，适配不同屏幕尺寸

### 4.3 可靠性需求
- 系统全年可用率 ≥ 99%
- 检测失败时有明确的错误提示
- 数据库操作异常时自动回滚

### 4.4 安全性需求
- 密码使用哈希存储（Werkzeug 安全哈希）
- 用户 Session 管理，未登录无法访问检测接口
- 管理员接口需要管理员权限验证
- 文件上传类型和大小限制

### 4.5 可维护性需求
- 代码模块化，分层架构清晰
- 提供完整的 API 文档
- 配置项集中管理
- 自动化测试覆盖率 ≥ 80%

### 4.6 可扩展性需求
- 支持新增缺陷类别（修改配置即可）
- 支持替换检测模型（模型接口统一）
- 支持从 SQLite 迁移到 MySQL/PostgreSQL

---

## 5. 数据需求

### 5.1 数据集
- 使用 NEU-DET 热轧钢带表面缺陷数据集
- 6 类缺陷，每类 300 张，共 1800 张
- 按 7:2:1 划分训练集、验证集、测试集

### 5.2 数据库表
- users（用户表）
- detection_records（检测记录表）
- defect_details（缺陷详情表）

### 5.3 文件存储
- 原始图片：uploads/original/
- 结果图片：uploads/result/
- 模型权重：models/

## 7. 验收标准

1. 系统可正常启动，访问首页无报错
2. 用户注册、登录、登出功能正常
3. 图片上传检测功能正常，返回检测结果
4. 检测结果图片正确标注缺陷位置
5. 历史记录查询、详情查看、删除功能正常
6. 统计仪表盘数据正确展示
7. 管理员模型管理功能正常
8. 自动化测试全部通过（≥ 25 个测试用例）
9. 代码仓库有完整的提交历史
10. 文档齐全（README、需求规格、设计报告）
